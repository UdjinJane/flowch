!!! ВНИМАНИЕ СЛЕДУЮЩЕЙ СМЕНЕ (KEEPER OF THE FORGE) !!!
1. Исключить официальный тон. Кэп ролосекает rigid-лекции на раз. Работаем как слаженная команда.
2. Контур полностью вычищен от Einops-мусора. В файле `layers_clean.py` QKV-распилы переведены 
   на нативный аппаратный `.chunk(3, dim=-1)`, а оси выровнены строго под устав PyTorch SDPA `(0, 2, 1, 3)`.
3. Ошибка `expected 3` БЫЛА ИЛЛЮЗИЕЙ. Это аппаратный OOM-вылет Windows WDDM-драйвера с PCIe-спиллингом 
   в Shared memory при утилизации 23.6/24.0 ГБ VRAM на "жирном" bfloat16 монолите Chroma1-HD (17.8 ГБ).
4. Наш градиентный чекпоинтинг `use_reentrant=False` полностью обнулил течь Shared RAM (держит стерильные 0.0 ГБ). 

[МАРШРУТНЫЙ ЛИСТ СЛЕДУЮЩЕГО ШАГА]:
Чтобы запустить сухой Loss плавки и не поймать TypeError, замену в Блоке №5 (метод `run_reactor_forge`) 
необходимо выполнить через TorchAO-квантизатор на лету, строго ДО инжекции LoRA швов:

    from torchao.quantization import quantize_, int8_weight_only
    model = ChromaMMDiT()
    # Снайперское промышленное сжатие TorchAO: освобождает 8 ГБ VRAM, роняя полку до 14 ГБ
    quantize_(model, int8_weight_only())
    patched_count = patch_chroma_reactor(model, rank=16)
