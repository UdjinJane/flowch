# [СЕКТОР 02]: ТЕХНИЧЕСКИЙ МАНИФЕСТ ДЛЯ СЛЕДУЮЩЕЙ СМЕНЫ
###############################################################################
1. ПОРЯДОК СБОРКИ В БЛОКЕ №5 НЕОТМЕНИМ: 
   Сначала льем структуры трансформера -> затем load_file(.safetensors) -> затем quantize_(model, int8_weight_only()) -> и ТОЛЬКО ПОТОМ patch_chroma_reactor. Нарушишь — С++ copy_ выбьет зубы рантайму.
2. ФЛАГ-ПРИКУРИВАТЕЛЬ НА СТАРТЕ БЛОКА №4:
   Строка `img_tokens.requires_grad_(True)` обязательна при `use_reentrant=True`. Без нее старый движок чекпоинта шлёт Autograd нахер и выдает мертвый градиент (Gradients will be None).
3. ПРИЧИНА ЧАСТОКОЛА И СВОПА 8.7 ГБ:
   Включая сквозной Autograd, PyTorch начинает трекать траекторию активаций сквозь замороженную базу. WDDM под завязку забивает кремний RTX 3090 и сливает эти промежуточные тензоры через PCIe в Shared RAM. Видяха простаивает (0% утилизации), ожидая прокачки буферов из ОЗУ.
4. КУРС НА МОДЕРНИЗАЦИЮ:
   В следующей сессии нужно нахер вырезать `torch.utils.checkpoint` и писать кастомные backward-хуки (`register_hook`) на матрицы LoRA, чтобы активации базовой модели вообще не вовлекались в глобальный граф PyTorch.
