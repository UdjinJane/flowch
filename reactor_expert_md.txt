# Реактор Chroma Unlocked v50: Экспертное руководство

## Общая информация
- **Название модели:** Chroma-fp8-scaled
- **Организация:** Clybius
- **Репозиторий:** [Hugging Face](https://huggingface.co/Clybius/Chroma-fp8-scaled)
- **Лицензия:** Apache 2.0
- **Базовая задача:** Text-to-Image (генерация изображений из текста)
- **Фреймворк:** PyTorch
- **Классификация контента:** NSFW/Sensitive Content Verified

---

## Архитектура и квантование
- **Архитектурная семья:** Flux MMDiT / Rectified Flow (Flow Matching)
- **Версия модели:** v50 (Annealed variant)
- **Основное разрешение:** 512x512
- **Тип квантования:**
  - FP8 Mixed Precision (e4m3fn / e5m2).
  - Compression: Learned SVD via TorchAO.
- **Состояние текстовых энкодеров:** Удалены из файла весов.
- **VAE-совместимость:** Flux-VAE-BF16 dependent.

---

## Аппаратные ограничения и бенчмарки
- **Статический VRAM:** 17.8 GB (при загрузке модели).
- **Рекомендуемое GPU:** NVIDIA RTX 3090 / RTX 4090 (24 GB VRAM).
- **VRAM-стратегия:**
  - Dynamic Offloading с `max_split_size_mb = 512`.
  - Рекомендация: `CudaSysMemToBase = 0` для блокировки spilling.

---

## Параметры обучения и LoRA
- **Базовый learning rate:** 2e-5
- **Gradient accumulation baseline:** 2
- **LoRA гиперпараметры (по умолчанию):**
  - Rank: 16
  - Alpha: 16
  - Target modules:
    - `to_q.0`
    - `to_k.0`
    - `to_v.0`
    - `to_out.0`
- **Frozen layers (bfloat16):**
  - `x_embedder` (FP8 запрещен).

## Файловая структура проекта (`Z:\flowch\src`)
| Файл                          | Роль                                                                 | Примечания
|-------------------------------|--------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| `ao_optim_monolith_v02.py`     | AdamW8bit оптимизатор для LoRA, управление памятью (int8 → float32).   | Запрещен самоимпорт, импортируется только из `train_engine_v02.py`.
| `chroma_math.py`               | Математические утилиты для Chroma (квантование, избежание коллизий).    | Используется через хак `sys.modules["src.math"] = chroma_math`.
| `config.py`                    | Конфигурация среды (запрет AMD-компиляции, CUDA настройка).             | Устанавливает `QUANTO_DISABLE_CPP_EXT`, `HF_DISABLE_COMPILING`, `FORCE_CUDA`.
| `dataset_v02.py`               | Обработка датасета и metadata.                                           | Интеграция с `Z:\flowch\dataset\mng_oks_bl\metadata.jsonl`.
| `generate_v02.py`              | Генерация выходных изображений и логирования.                           | Сохраняет результаты в `Z:\flowch\output\images`.
| `get_dataloader_v02.py`        | Загрузка данных для обучения (dataloader).                               | Используется в `train_engine_v02.py`.
| `layers.py`                     | Базовые слои модели (LoRA, RoPE).                                       | Включает логику квантования через `_фильтр_магистрали()`.
| `lora_core_v02.py`             | Ядро обучения LoRA (380 тензоров).                                      | Интегрируется в `train_engine_v02.py`.
| `model_runner_v02.py`           | Запуск модели, management latents и текста.                              | Основной кондуктор для инференса/обучения.
| `model.py`                      | Основная модель Chroma Unlocked v50 (FP8).                               | Загружается из `Z:\flowch\models_core\transformer`.
| `step_executor_v02.py`         | Выполнение шагов обучения/инференса.                                     | Обрабатывает timesteps, проверки на OOM.
| `step_optimizer_v02.py`        | Оптимизация шагов (clipping градиентов).                                 | Используется в контуре обратного распространения.
| `telemetry_logger.py`           | Логирование телеметрии и журналирования ошибок.                          | Сохраняет логи в `Z:\flowch\output\logs`.
| `train_engine_v02.py`           | Основной цикл обучения (LoRA, RoPE, OOM-обработка).                      | Точка входа для процесса обучения.

## Ограничения и запреты
1. **VRAM:**
   - Лимит: 21.0 GB (dynamic offloading при превышении).
   - Рекомендация: `CudaSysMemToBase = 0`.

2. **Режимы работы:**
   - Боевой режим (`USE_EMULATORS = False`): Эмуляторы запрещены.

3. **Запреты:**
   - Самоимпорт: Запрещен `from ao_optim_monolith import ...`.
   - Хардкодные пути: Нет `sys.path` внутри `ao_optim_monolith_v02.py`.
   - FP8 для frozen layers: Запрещен для `x_embedder`.

---

## Ключевые проверки и логика
1. **VRAM и OOM:**
   ```python
   del pred_tensor, pred_tensor_f32, weight_mask, loss_active, target_flow
   del latents, prompt_embeds, t_raw, t_attr, noise, noisy_latents, packed_noisy_latents
   del img_ids, txt_ids_aligned, kwargs_mask
   ```

2. **Timestep:**
   - Должен быть в `[0.0, 1.0]` с маржином (`epsilon=1e-5`).

3. **LoRA-градиенты:**
   - Clipping: `max_norm=1.0`.
   - Проверка на zero-градиенты.

## Инструкции по эксплуатации
1. **Загрузка модели:**
   ```python
   import torch
   from safetensors.torch import load_file
   model = load_file("chroma-unlocked-v50-annealed_float8_e4m3fn_learned_svd.safetensors")
   ```

2. **Обработка latents и текста:**
   - Latents: `(B, 16, H, W)` (H и W должны быть четными).
   - Text embeds: `(1, 256, 4096)`.

3. **Обучение LoRA:**
   - Использовать `ao_optim_monolith_v02.py` для AdamW8bit.
   - Проверки:
     ```python
     torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
     ```

4. **Журналирование:**
   - Логи сохраняются в `Z:\flowch\output\logs`.
