## 🔧 1. ОСНОВНЫЕ МОДУЛИ РЕАКТОРА

### 1.1 Базовый Трансформер (FluxTransformer2DModel)
```mermaid
graph TD
    A[FluxTransformer2DModel\n(float8_e4m3fn)] --> B[38 LoRA мишеней\n(to_q.0, to_k.0, ...)]
    B --> C[Quantize: int8_weight_only()\n⚠️ Несовместимо с float8]
    C --> D[Base Model Weights\n(19 layers, 64 channels)]
```

**Критика:**
- Нет валидации на `dtype` при загрузке весов.
- Потенциальный OOM при загрузке базовых весов (не проверено).

---

### 1.2 Оптимизатор (AdamW8bit)
```mermaid
graph TD
    E[AdamW8bit\n(8-bit gradients)] --> F[Quantize: _quantize_8bit()]
    F --> G[Dequantize\n⚠️ Нет NAN/INF проверки]
    G --> H[Step:\nAdamW math + FP32 unpacking]
    H --> I[Re-quantize\n⚠️ Риск NaN/Inf в моментах]
```

**Критика:**
- Нет проверки на `max_val == 0`.
- Нет валидации градиентов на конечность (`torch.isfinite`).

---

### 1.3 Данные (CachedFluxDatasetV02)
```mermaid
graph TD
    J[metadata.jsonl] --> K[RAM Load:\nt5_hidden (1, 256, 4096)\n⚠️ Должен быть срез до (256, 4096)]
    K --> L[latents (16, 128, 128)\n⚠️ Несоответствие VAE scale=8]
    L --> M[VAE Decode:\n(16, 64, 64) → (3, 512, 512)]
```

**Критика:**
- Нет проверки на размерность латентов.
- Нет валидации T5 эмбеддингов.

---

### 1.4 Пайплайн (ChromaPipeline)
```mermaid
graph TD
    N[ChromaPipeline] --> O[FluxPipeline\n(2D)]
    O --> P[RoPE Grid:\nimg_ids (H//2, W//2, 3)\ntxt_ids (1, 256, 3)]
    P --> Q[Transformer Call:\npacked_noisy_latents, prompt_embeds, timestep]
    Q --> R[Pred Tensor:\nSqueeze dim=1\n⚠️ Нет проверки на shape]
```

**Критика:**
- Нет валидации `pred_tensor` после squeeze.
- Нет проверки на OOM в `ChromaPipeline`.

## 🔄 2. ПЛАВКА (Train Loop)
```mermaid
graph TD
    S[main_train_loop] --> T[Initialize:\nAdamW8bit, FluxLoraCoreV02]
    T --> U[Epoch Loop:\nfor epoch in range(1, NUM_EPOCHS+1)]
    U --> V[Frame Step:\nexecute_single_frame_step]
    V --> W[Loss Calculation:\nMSE + weight_mask]
    W --> X[Optimizer Step:\nAdamW8bit.step()\n⚠️ Нет OOM проверки]
    X --> Y[Checkpointing\n⚠️ Нет dynamic offloading]
```

**Критика:**
- Нет динамического оффлоада при OOM.
- Нет валидации градиентов на `NaN/Inf`.

## ⚠️ БЛОК РИСКОВ И ОШИБОК (ФУТЕР)

### 1. Критические риски
| Риск                     | Описание                                                                 | Уровень |
|-------------------------|----------------------------------------------------------------------------|---------|
| **OOM (VRAM)**          | Нет dynamic offloading, только `empty_cache()`. Превышение 21.0 GB → полный блэкаут шхуны.
| **NaN/Inf в градиентах** | Нет проверки на конечность в `AdamW8bit.step()` или лоссе MSE.
| **Несовместимость квантования** | `int8_weight_only()` не работает с float8_e4m3fn (ошибка TorchAO).
| **Размерности данных** | LATENTS: `(16, 128, 128)` vs VAE scale → ожидается `(16, 64, 64)`.

### 2. Потенциальные ошибки
| Ошибка                          | Причина                                                                 | Последствие                                  |
|---------------------------------|--------------------------------------------------------------------------|-----------------------------------------------|
| **Падение лосса на `inf`**      | Нет валидации `torch.isfinite()` для `pred_tensor` или `target_flow`.
| **VRAM фрагментация**           | Нет `max_split_size_mb=512`, `garbage_collection_threshold:0.8`.     |
| **Несовместимость PEFT/TorchAO** | LoRA веса квантируются `int8_weight_only()`, а модель работает в float8_e4m3fn.
| **Deadlock в autograd**          | Нет сброса графа Autograd между фреймами (`zero_grad(set_to_none=True)`).

## 🔧 РЕКОМЕНДАЦИИ ДЛЯ ГЕММЫ

### 1. Неотложные действия
- **Проверить VRAM после загрузки базового трансформера.**
  ```python
  import torch
  transformer = FluxTransformer2DModel.from_config(config_dict).to(dtype=torch.bfloat16)
  state_dict = load_file(TrainConfig.MODEL_SINGLE_FILE, device="cpu")
  clean_state_dict = {k.replace("model.diffusion_model.", ""): v for k, v in state_dict.items()}
  transformer.load_state_dict(clean_state_dict, strict=False)
  allocated_vram = torch.cuda.memory_allocated() / (1024 ** 3)
  if allocated_vram > TrainConfig.VRAM_LIMIT_GB - 2.0:
      print(f"[КРИТ] Базовый трансформер занимает {allocated_vram:.2f} GB! Потолок: {TrainConfig.VRAM_LIMIT_GB}")
  ```
- **Добавить OOM проверку в `train_engine_v02.py`.**
  ```python
  def _check_vram():
      allocated = torch.cuda.memory_allocated(device) / (1024 ** 3)
      if allocated > TrainConfig.VRAM_LIMIT_GB - 0.5:
          print(f"[КРИТ] VRAM OOM! Active: {allocated:.2f} GB")
          torch.cuda.empty_cache()
          gc.collect()
          sys.exit(1)
  ```

### 2. Улучшения для стабильности
- **Валидация градиентов на `NaN/Inf`.**
  ```python
  for param in trainable_params:
      if param.grad is not None and not torch.isfinite(param.grad).all():
          print("[КРИТ] Обнаружен NaN/Inf в градиентах!")
          sys.exit(1)
  ```
- **Замена `int8_weight_only()` на явное float8 квантование.**
  ```python
  quantize_(transformer, "weight_only", dtype=torch.float8)  # Вместо int8_weight_only()
  ```

### 3. Структурные улучшения (для будущих версий)
- **Разбить `lora_core_v02.py` на:**
  - `init_model_v02.py` (загрузка весов, квантование).
  - `apply_lora_v02.py` (применение LoRA, валидация мишеней).
- **Добавить dynamic offloading в `config.py`.**
  ```python
  os.environ["PYTORCH_CUDA_ALLOC_CONF"] = (
      "max_split_size_mb:512,"  # Агрессивный split для уменьшения фрагментации
      "garbage_collection_threshold:0.8,"
      "expandable_segments:True"
  )
  ```

### 4. Запреты на изменения (стабильность V02_STABLE_COMPLIANCE)
- **Не изменять:**
  - Структуру `ao_optim_monolith_v02.py`.
  - Логику плавки в `train_engine_v02.py` без аппрува.
  - Обращаться к весам `ModuleList.weight` (даже для отладки).
- **Не добавлять:**
  - Комментарии с TODO, pass или троеточия.
  - Локальные запуски кода (нет доступа к GPU шхуны).
