== SECTION 1: INITIALIZATION & CONFIGURATION (PHASES 0–2) ==

[FILE]: config.py
    FUNCTIONALITY:: Global configuration hub containing all hyperparameters, paths, and environment variables required for the training loop. Defines dataset/cache/model directories in relative form; sets VRAM limits (~21GB), batch size=1, max sequence length=128 (T5 truncation to prevent RoPE explosion); LoRA rank/alpha targets ("img_attn.qkv" etc.); and torch.cuda memory management settings for WDDM Windows drivers.
    KEY VARIABLES:  
        - DATASET_DIR = "dataset/mng_oks_bl/" → metadata.jsonl + text_cache/*.pt (T5) / latent_cache/* (images). 
      OUTPUT_DIR, LOGS_DIR paths; MODELS_CORE/transformer/vae/text_encoder weights (.safetensors); LORA_RANK=4 ALPHA=4.
        - VRAM_LIMIT_GB = 21.0 • PYTORCH_CUDA_ALLOC_CONF(max_split_size_mb:64,gc_threshold:.9).


[FILE]: lora_core_v02.py  
    FUNCTIONALITY:: Initializes the Flux Chroma transformer from safetensors checkpoint, cleans weight key names (strip "model.diffusion_model." prefix), auto-detects double/single block depths by scanning state_dict keys; applies TorchAO float8_weight_only quantization with custom filter_fn to avoid small layers (<16 dims); wraps model in PEFT LoRA(r=4) targeting only ["img_attn.qkv","txt_qkvvqkl" "linear/2"]; freezes all backbone weights except x_embedder (casted back to bfloat16 for numerical stability).
    KEY FUNCTIONS:  
        load_file() → clean_keys(), detect_blocks, CHROMA(chroma_params), quantize_(transformer,float8_weight_only(filter_fn)), get_peft_model().


[FILE]: dataset_v02.py / get_dataloader_ v. py (REAL DATASET PATH) 
FUNCTIONALITY:: CachedFluxDatasetV02 loads metadata.jsonl once at startup, then preloads all text_cache/*.pt + latent_cache/* into RAM for zero-I/O inference during training; returns batches of shape {"latents": [B,C,H/8,W/8], "prompt_embeds":[ B,T5_L×D]} where T5 sequence is truncated to MAX_SEQ_LEN=128.
    KEY FUNCTIONS:  
        - CachedFluxDatasetV02.__init__(): iterates metadata.jsonl, loads each pair of .pt files (T5 + latent), squeezes batch axis [B,C,H/8,W//] → returns {"latents":..., "prompt_embeds"}. 
      __len__, _getitem_.
        - get_dataloader_v02() creates DataLoader(batch_size=1, shuffle=True).


[FILE]: model.py / layers.py (SHARED MODULES — CORE TRANSFORMER ARCH)  
    FUNCTIONALITY:: Pure PyTorch implementation of the Flux Chroma MMDiT transformer without Diffusers dependencies. Contains: EmbedND(ROPE), SelfAttention(qkv chunking + attention()), DoubleStreamBlock(img/txt parallel MLP+attn.), SingleStreamBlock(combined stream linear1/2 modulation lin, LastLayer(out_channels=64).
    KEY CLASSES & METHODS:  
        - Chroma(nn.Module): __init__(params) builds img_in.txt_in.pe_embedder.double_blocks(single_blocks.guidance_in.approximator.final_layer. 
          forward(img,timesteps_txt_ids,img_mask,...)) returns output logits [B,C].


[FILE]: chroma_math.py (SHARED MATH UTILITIES)  
    FUNCTIONALITY:: Implements RoPE positional embeddings and attention computation compatible with FlashAttn2 fallback; provides rope(pos,dim,theta), apply_rope(q,k,prefix_cis).
      KEY FUNCTIONS:attention() uses torch.nn.functional.scaled_dot_product_attention if flash_attn unavailable.


== SECTION 3 STEP EXECUTION & COMPUTE GRAPH (PHASES 4–5) ==

[FILE]: step_executor_v02.py  
    FUNCTIONALITY:: Executes one training frame in a checkpointed manner: packs latents to patches(16×, view + permute flatten), generates img_ids for RoPE positioning; constructs input dict {packed_latents,img_ids,txt_mask,pooled_proj_dummy}, wraps run_lora_model_step inside torch.amp.autocast(dtype=torch.bfloat16) with checkpoint=True use_reentrant=False to save VRAM during forward pass.
    KEY FUNCTIONS:  
        pack_latents_to_patches(latents): 4D →3 D, patch_size=16 (p×H// p ×W//). 
          generate_chroma_img_ids(h,w): creates [h/p ,w /_,_ ] grid of positions for RoPE alignment.
      execute_single_frame_step(mega_batch,...) returns {loss_val,t_attr_cpu,pred_tensor,target_flow}.


[FILE]: model_runner_v02.py  
    FUNCTIONALITY:: Tensor routing layer that reconstructs the FluxTransformer forward interface expected by ChromaPipeline: upcasts all norms to bfloat16; reshapes timesteps into 1D batch-compatible vector; invokes target_engine.forward(img,txt_ids,txt_mask,...); handles output tuple unpacking and dtype casting back.
    KEY FUNCTIONS::  
        run_lora_model_step(lora,batch,packed_noisy_latents,img_ids.txt_masks,..): returns pred_tensor [B,C] ready for scheduler step in diffusion loop (simulated via flow matching).


[FILE]: chroma_pipeline.py / generate_v02.py (INFERENC E MODE) 
    FUNCTIONALITY:: ChromaPipeline wraps FluxTransformer+VAE+Scheduler from diffusers; used only for inference testing. Loads T5/CLIP embeddings directly from text_cache/*.pt, constructs prompt_attn_mask ones(B,T), computes pooled_projections as mean over CLIP dimension, calls pipe(prompt_embeds,height=width,resolution) returning decoded PIL images saved to OUTPUT_DIR/images/. 
    NOTE: This path is bypassed during main training loop (use step_executor instead).

== ARCHITECTURE SUMMARY ==

CHROMA V02 REACTOR operates in MONOLITHIC MODE on Windows WDDM/RTX 3090 to train Flux-LoRA models via flow-matching (rectified diffusion) with checkpointed forward passes for VRAM conservation. The main training loop is driven by step_executor_v02.py, which orchestrates:

1→ INITIALIZATION → config + lora_core loads Chroma weights in CPU mode and quantizes to float8; dataset preloads latents into RAM (zero-I/O during train).
  
   2 STEP EXECUTION packs latent images into patches(6×3) for RoPE alignment, constructs input ports {packed_latent,img_ids,txt_mask}, runs transformer forward via checkpointed model_runner.run().

      4→ OPTIMIZATION quantizes momentum states to int8 before each gradient step (reduces VRAM pressure), clips gradients(max_norm=1.0).
        FLUSH TELEMETRY aggregates metrics every N steps, writes session log file for monitoring loss/mean/std over time


All shared libraries(model.py / layers.chroma_math) are imported directly without external dependencies beyond PyTorch and PEFT + TorchAO quantization stack (torchao.float8_weight_only() filter_fn skips small linear modules).

VRAM GUARDRAILS:  
- All activations casted to bfloat16 before forward pass.
   OptimStateTensor stores moments as int×scale → reduces VRAM footprint by ~2–3GB on RTX 3090(≈ 48 GB total, usable ≈21).

INFERENCE PATH (OPTIONAL):  
generate_v02.py uses ChromaPipeline from diffusers to decode saved images via FakeVAE; intended only for testing/debugging.
