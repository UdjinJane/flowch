## Описание функциональности модулей

### train_engine_v02.py
- **Функциональность:**
  - Загрузка данных из датасета.
  - Цикл обучения с контролем VRAM (<21.0 GB).
  - Логирование и отладка тахометра.
  - Контроль фрагментации памяти (боевой режим).

### lora_core_v02.py
- **Функциональность:**
  - 8-битная оптимизация AdamW (`ao_optim_monolith_v02.py`).
  - Динамический кастинг градиентов int8/float32.
  - Контроль фрагментации VRAM (экономия до 2-3 ГБ).

### model_runner_v02.py
- **Функциональность:**
  - Запуск и управление моделью Chroma Unlocked v50.
  - Геометрия RoPE (1280 токенов сетки без батч-размерности).
  - Взаимодействие с текстовым энкодером и VAE-модулем.

### generate_v02.py
- **Функциональность:**
  - Decode latents (VAE).
  - Postprocessing PNG.
  - Статистика скорости (it/s).
  - Фиксация изображений на SSD.

## Ключевые ограничения и режимы
- **VRAM:** Жесткий лимит — 21.0 ГБ (OOM при превышении).
- **Режим эмуляции:** `USE_EMULATORS: bool = False` (боевой режим по умолчанию).
- **Запреты:**
  - Самоимпорт (`from ao_optim_monolith import ...`) в шапке.
  - Хардкодные пути `sys.path`.
  - Вангование без доказательств.

## Инструкции по работе
1. **Боевой режим:**
   - Активируется по умолчанию (`USE_EMULATORS = False`).
   - Реальная загрузка весов VAE и трансформера.
2. **Эмуляция (холостой режим):**
   - `USE_EMULATORS = True` для отладки без реальной нагрузки.

## Примечания
- Все изменения вносятся поблочно без заглушек (`TODO`, `pass`, троеточий).
- Контроль фрагментации памяти на RTX 3090 (метод `_cast_to_int8` в `lora_core_v02.py`).
